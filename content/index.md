# Bible Background

Reference library for concise biblical context notes (historical background, canonical placement, and intertext links).

## How to use
- Browse by book and chapter using the left navigation or direct URLs (e.g., `/genesis/2/`).
- Use search in the header to jump to any passage.
- Each page keeps a predictable path: `/book-name/chapter-number/`.
